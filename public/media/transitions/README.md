# Transition Videos

Drop your 5-second MP4 videos here. Name them to match the map:

| File | Transition |
|------|------------|
| `gate-to-lobby.mp4` | Age gate -> Castle lobby |
| `lobby-to-hall.mp4` | Castle lobby -> Grand Hall |
| `hall-to-room.mp4` | Grand Hall -> Any performer room |
| `hall-to-casino.mp4` | Grand Hall -> Casino game |
| `room-to-vip.mp4` | Room -> Private show (Go Private) |
| `lobby-to-room.mp4` | Lobby -> Room (direct from category card) |
| `vip-to-room.mp4` | Private show -> Back to room |
| `hall-to-lobby.mp4` | Grand Hall -> Back to lobby |
| `room-to-hall.mp4` | Room -> Back to hall |

All videos should be:
- MP4 (H.264 codec)
- ~5 seconds
- 1920x1080 or 1280x720
- No audio needed (plays muted)

If you have fewer than 9 videos, just name what you have.
Routes without a matching video will navigate instantly (no transition).
